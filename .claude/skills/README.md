# Skills de Tauri v2

Las 39 carpetas `tauri-*` en este directorio vienen de
[dchuk/claude-code-tauri-skills](https://github.com/dchuk/claude-code-tauri-skills)
(generadas a partir de la documentación oficial de Tauri v2, enero 2026).
Cubren comandos Rust, IPC, capabilities/permisos, empaquetado y distribución
(Windows/macOS/Linux/iOS/Android), firma de código, y más — instaladas
2026-09-25 porque `apps/desktop` usa Tauri v2 y ninguna otra skill instalada
cubre Rust/Tauri.

El repo origen no tiene archivo de licencia explícito, pero su único
propósito es ser copiado a `.claude/skills/` de otros proyectos.

Si Tauri v2 cambia de forma importante después de enero 2026, estas skills
pueden quedar desactualizadas en ese punto — verifica contra
`node_modules`/la documentación oficial si algo no cuadra.
